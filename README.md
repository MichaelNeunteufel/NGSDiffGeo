# NGSDiffGeo
This is an add-on package to NGSolve for differential geometry support. We focus on Riemannian manifolds. Examples and tutorials can be found in the [documentation](https://michaelneunteufel.github.io/NGSDiffGeo/).

The current source requires NGSolve 6.2.2608.post166.dev0 or newer, with the
DAG-based coefficient-function API. For NGSolve 6.2.2607 or stable 6.2.2608,
use NGSDiffGeo v0.3.1. Rebuild NGSDiffGeo after changing the NGSolve installation.
